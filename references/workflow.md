## 整体流程概览

```
输入PDF/文本
    ↓
1. 提取文本内容 (extract_pdf.py)
    ↓
2. 按章节划分内容
    ↓
3. 为每章生成慢语速朗读音频 (text_to_audio_plus)
    ↓
4. 格式化HTML内容（金句高亮、引用卡片、要点块）
    ↓
5. 生成最终HTML (generate_html.py)
    ↓
6. 自检 (shot.py) 并交付
```

## 第一步：内容提取与整理

### PDF提取

使用 `scripts/extract_pdf.py` 提取PDF文本：

```bash
python scripts/extract_pdf.py <pdf_path> --output <output_json>
```

**注意事项：**
- 如果PDF是扫描件（图片型），需要先OCR处理
- 提取后检查文本质量，删除页眉页脚、页码等无关内容
- 保留段落结构，不要把所有文字连成一片

### 文本整理

提取后需要人工/AI整理：
1. 删除重复的页眉、页脚、页码
2. 合并被分页打断的段落
3. 修正明显的OCR错误
4. 保留章节标题、小标题等结构信息

## 第二步：章节划分

### 划分原则

1. **按原书结构划分**：优先使用原书的章节标题
2. **每章长度适中**：建议每章文字量在2000-5000字之间
3. **音频分段**：每章音频按每段约400-500字划分（对应约2分钟朗读）
4. **特殊章节**：序言、引言、附录等单独作为一章

### 章节元数据

每个章节需要记录：
- `id`: 英文标识符（如 `chapter1`, `preface`, `intro`）
- `num`: 章节编号显示（如 `CHAPTER 01`）
- `title`: 章节标题
- `subtitle`: 章节副标题（可选）
- `content_html`: 格式化后的HTML内容
- `audios`: 音频列表

## 第三步：音频生成

### 工具限制

- 使用 `text_to_audio_plus` 工具生成音频
- **单次最长120秒（2分钟）**，无法生成更长音频
- 因此一个章节需要拆分为多个2分钟片段

### 音频生成规范

**Prompt模板：**
```
温暖沉稳的中年男性声音，舒缓慢速朗读，像睡前讲故事一样，语速比正常慢30%，停顿自然，有节奏感。朗读以下内容：
<文本内容>
```

**关键参数：**
- `duration`: 不超过120秒（建议100-115秒，留余量）
- 每段文本控制在400-500字左右

**分段策略：**
1. 在自然段落边界分段，不要在一句话中间断开
2. 每段以完整句子结束
3. 记录每段的序号和文本，便于后续核对

**音频URL记录：**
生成后立即记录每个音频的URL，格式：
```json
{
  "label": "第1段（慢语速）",
  "url": "https://aka.doubaocdn.com/s/xxxxx"
}
```

### 连续播放实现

HTML模板已实现自动连续播放：
- 一个音频播放结束后，自动播放同章节的下一段
- 播放时自动滚动到对应音频播放器位置

## 第四步：HTML内容格式化

### 基础段落

普通段落使用 `<p>` 标签，默认首行缩进2字符：
```html
<p>这是普通段落内容...</p>
```

不需要缩进的段落（如列表项、对话）添加 `no-indent` 类：
```html
<p class="no-indent">不需要缩进的内容</p>
```

### 金句高亮

书中的核心观点、精彩句子使用预设高亮（浅黄色背景）：
```html
<span class="highlight">这是需要高亮的金句</span>
```

**高亮原则：**
- 每章高亮3-5处核心观点
- 高亮完整的句子，不要只高亮几个词
- 选择真正有启发性、值得记住的句子

### 引用卡片

特别重要的金句、名人名言使用引用卡片突出显示：
```html
<div class="quote-card">
  <p>这是引用卡片中的金句内容...</p>
  <div class="source">—— 来源/作者</div>
</div>
```

**使用场景：**
- 章节开头的核心论点
- 书中引用的名人名言
- 特别震撼、值得反复品味的句子

### 要点块

结构化的要点、方法论使用要点块（左侧色条+浅色背景）：
```html
<div class="key-points">
  <p><strong>要点一：</strong>这是第一个要点的说明</p>
  <p><strong>要点二：</strong>这是第二个要点的说明</p>
</div>
```

**使用场景：**
- 方法论总结
- 步骤说明
- 多个并列要点

### 选择题/测试题

书中的测试题使用普通段落，答案用浅色小字标注：
```html
<p><strong>1. 题目内容？</strong></p>
<p>A. 选项A　　B. 选项B</p>
<p style="color: var(--text-light); font-size: 14px; margin-top: 20px;">（答案：B）</p>
```

## 第五步：生成HTML文件

### 配置文件格式

创建JSON配置文件，包含书籍元数据和所有章节信息：

```json
{
  "book_title": "轻松主义",
  "book_subtitle": "让关键的事情变得容易做",
  "author": "[英] 格雷戈·麦吉沃恩",
  "translator": "范兆明 译",
  "cover_label": "EFFORTLESS · 精 读 版",
  "footer_text": "愿你找到最省力的路径，让重要的事变得容易做",
  "storage_key": "effortless",
  "chapters": [
    {
      "id": "chapter1",
      "num": "CHAPTER 01",
      "title": "推荐序1",
      "subtitle": "放轻松带来的双重复利 —— 杨天南",
      "content_html": "<p>章节内容...</p>",
      "audios": [
        {"label": "第1段（慢语速）", "url": "https://..."},
        {"label": "第2段（慢语速）", "url": "https://..."}
      ]
    }
  ]
}
```

### 生成命令

```bash
python scripts/generate_html.py --config <config.json> --output <output.html>
```

### 输出目录建议

在书籍所在目录下创建子目录：
```
<书籍目录>/
└── <书名>-带音频阅读/
    ├── <书名>-带音频精读.html
    ├── chapters.json (章节配置)
    └── _shots/ (自检截图，自动生成)
```

## 第六步：自检与交付

### 自检

使用 html skill 的 `shot.py` 脚本自检：

```bash
python <html_skill_dir>/scripts/shot.py <html_path> --only desktop
```

**检查要点：**
1. 页面布局正常（左右两栏）
2. 封面、章节标题显示正确
3. 音频播放器正常显示
4. 高亮、引用卡片、要点块样式正确
5. 无控制台错误
6. 响应式布局（移动端检查）

### 交付

使用 `present_files` 工具交付HTML文件：

```
artifacts:
  - name: <书名>-带音频精读.html
    source: <html文件绝对路径>
```

**交付说明应包含：**
1. 文件位置
2. 核心功能介绍（左右布局、高亮、连续播放）
3. 使用方法（如何开启高亮、如何播放音频）
4. 音频覆盖范围（哪些章节已有音频）
5. 后续可补充的内容

## 常见问题

### Q: 音频工具只能生成2分钟，用户想要10分钟一章怎么办？
A: 在HTML中实现连续播放列表，把多个2分钟片段按顺序排列，播完自动连播下一段，用户体验上等同完整章节音频。在交付说明中向用户解释这个限制。

### Q: 用户高亮功能如何保存？
A: 使用 localStorage 保存，模板已实现。每本书用不同的 `storage_key` 区分。

### Q: PDF提取后文本质量差怎么办？
A: 检查是否为扫描件，如果是需要先OCR。如果是文字型PDF但排版混乱，可以尝试调整提取参数，或人工整理关键章节。

### Q: 如何处理书中的图片、图表？
A: 当前版本暂不支持图片插入。如果图片包含重要信息，可以在文字中描述，或在后续版本中添加图片支持。
